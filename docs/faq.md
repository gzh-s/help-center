# 常见问题（FAQ）

这里整理了常见的问题。如果这里没有你的问题，请联系管理员（QQ：911576136）解决。

## 账号相关

**Q: 我收不到注册验证邮件怎么办？**

A: 请检查你的垃圾邮件箱。如果还是没有，可以尝试换一个邮箱（推荐使用 QQ 邮箱或 Gmail）。

**Q: 我忘记密码了，怎么重置？**

A: 在登录页面点击 **忘记密码**，输入你的注册邮箱，系统会发送重置链接。

## 评测相关

**Q: 提交代码后一直显示"等待评测"，是卡住了吗？**

A: 不是。当评测队列繁忙时，你的提交会排队等待。如果等待超过5分钟，可以尝试刷新页面或重新提交一次。

**Q: 我的代码在自己电脑上运行正常，在这里却报错？**

A: 请排查以下情况：
1. 递交时选错了编程语言
2. Java 的主类名没有使用 "Main"
3. 对 C/C++ 选手的特别提醒：
  -  __int64 在 GNU C++ 中应写成 long long 类型
  -  main() 返回值必须定义为 int ，而不是 void
  -  for 语句中的指标变量 i 将会在如"for (int i = 0...) {...}"语句之后变为无效
  -  itoa 不是一个通用 ANSI 函数（标准 C/C++ 中无此函数）
  -  printf 中使用 %lf 格式是不正确的
