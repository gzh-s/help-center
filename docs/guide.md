# 快速开始

欢迎来到 YJOJ！

## 1. 注册账号

1. 打开首页，点击右上角的 **注册** 按钮。
2. 填写你的 **邮箱地址**（用于找回密码和接收通知）
3. 登陆邮箱，点击验证链接。
4. 设置一个用户名和密码。
5. 点击注册，账号注册完成！

## 2. 找到题目

1. 登录后，点击顶部导航栏的 **题库**。
2. 你可以按照难度和或分类筛选题目。
3. 点击任意题目的标题，进入题目详情页。

## 3. 提交代码

1. 在题目详情页，阅读题目描述和输入输出要求。
2. 在你本地的IDE（如 VS Code、Dev-C++）中编写代码，你也可以使用在线IDE编写代码。
3. 点击 **提交** 按钮。
4. 将你的代码粘贴到代码框中。
5. 选好编程语言，点击提交。

## 4. 查看评测结果


提交后，系统会开始评测。你可以在 **评测结果** 页面查看结果
。
| 结果 | 含义 |
| :--- | :--- |
| 通过 (AC) | 你的代码正确通过了所有测试数据。 |
| 答案错误 (WA) | 你的程序输出了错误的结果，请检查逻辑。 |
| 运行超时 (TLE) | 你的程序运行时间超过了限制，需要优化算法。 |
| 编译错误 (CE) | 代码语法有误，请检查编译器报错信息。 |

---

*如果在操作中遇到问题，请查看 [常见问题](/faq) 页面。*
